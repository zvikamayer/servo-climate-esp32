# בקרת סרוו + מזג אוויר (ESP32-S3)

אתר ששולט בסרוו ומציג שעון, טמפרטורה ולחות עם גרף היסטוריה - בדיוק כמו
`servo_timer_esp32`, רק עם תחנת מזג אוויר (DHT11) בנוסף.

## איך זה עובד

- **סרוו כמו כפתור**: באתר בוחרים זווית עם סליידר ולוחצים "הפעל". הסרוו נע
  לזווית שנבחרה, עוצר שם רגע (`HOLD_MS`, ברירת מחדל 0.8 שניות), וחוזר לבד
  לזווית ההתחלה (`REST_ANGLE`, ברירת מחדל 0°) - בלי צורך ללחוץ שוב.
- **יומן לחיצות**: כל לחיצה נרשמת עם שעה+תאריך (לפי שעון מסונכרן מהאינטרנט)
  ונשמרת ב-NVS של הבקר, כך שהיא שורדת אתחול/הפסקת חשמל.
- **גרף מזג אוויר**: החיישן נקרא כל כמה שניות לתצוגה חיה, ונקודה אחת לשעה
  נשמרת להיסטוריה (עד 48 שעות אחרונות כברירת מחדל - ראה `MAX_HISTORY_POINTS`
  ב-`.ino` אם רוצים טווח ארוך יותר).
- **עדכון חי**: MQTT ציבורי (`broker.hivemq.com`), בלי טוקן/סיסמה/חשבון -
  בדיוק כמו שאר הפרויקטים.

## חיווט

| רכיב | פין ב-ESP32-S3 |
|---|---|
| סרוו - חוט אות | GPIO6 |
| סרוו - חוט (+) | 5V |
| סרוו - חוט (-) | GND |
| DHT11 - VCC | 3.3V |
| DHT11 - DATA | GPIO4 |
| DHT11 - GND | GND |

אם ה-DHT11 שלך הוא חיישן "עירום" (3 פינים בלי לוחית) - יש להוסיף נגד משיכה
10kΩ בין DATA ל-VCC. מודולים מוכנים על לוחית קטנה כוללים אותו כבר על הלוח.

## התקנה

1. **ספריות ב-Arduino IDE** (Library Manager): `PubSubClient`, `ArduinoJson`,
   `ESP32Servo`, `DHT sensor library` (Adafruit) + `Adafruit Unified Sensor`.
   אם כבר עבדת על אחד הפרויקטים האחרים במחשב הזה - הן כנראה כבר מותקנות.
2. פתחי את `servo_climate_esp32.ino`, בחרי בורד ESP32-S3 מתאים ופורט, ולחצי
   Upload. פרטי הוויפי כבר ממולאים ב-`secrets.h` (אותה רשת כמו בפרויקטים
   האחרים בבית).
3. פתחי **Serial Monitor** (115200) ווודאי שרואים "מחובר. IP=..." ואז
   "MQTT מחובר.".
4. פתחי את `docs/index.html` בדפדפן (או פרסמי אותו לאירוח סטטי כלשהו, למשל
   GitHub Pages - ראה הוראות למטה) - הוא מתחבר ישירות ל-MQTT מהדפדפן, בלי
   צורך בשרת.

## פרסום האתר ב-GitHub Pages

1. תצרי ריפו חדש וריק ב-https://github.com/new (לא חייב להיות ציבורי, אבל
   ציבורי בסדר גמור - האתר לא כולל שום סוד, הוא רק מתחבר ל-MQTT הציבורי).
   **אל תסמני** "Add a README" - הריפו המקומי כבר מכיל אחד.
2. בתיקיית הפרויקט (`servo_climate_esp32`), בטרמינל:
   ```
   git init
   git add .
   git commit -m "התקנה ראשונית"
   git branch -M main
   git remote add origin https://github.com/<שם-המשתמש-שלך>/<שם-הריפו>.git
   git push -u origin main
   ```
   שימי לב: `secrets.h` (עם סיסמת הוויפי) לא ייכלל בהעלאה - הוא ב-`.gitignore`
   מראש, בדיוק כדי שלא יגיע לריפו ציבורי.
3. ב-GitHub: **Settings -> Pages**. תחת "Build and deployment" בחרי
   Source: "Deploy from a branch", Branch: `main`, תיקייה: `/docs`, ולחצי
   Save.
4. אחרי דקה-שתיים האתר יהיה זמין בכתובת שתופיע שם למעלה (בד"כ
   `https://<שם-המשתמש-שלך>.github.io/<שם-הריפו>/`).
5. כל עדכון עתידי לאתר: עריכה של `docs/index.html`, ואז
   `git add docs/index.html && git commit -m "עדכון" && git push` - האתר
   מתעדכן אוטומטית תוך דקה-שתיים.

## בדיקה מהירה של הגרף בלי לחכות שעה

`HISTORY_INTERVAL_MS` ב-`.ino` קבוע לשעה. לבדיקה - אפשר להקטין זמנית לערך
כמו `60000UL` (דקה), להעלות מחדש, לראות שנקודות מצטברות בגרף, ואז להחזיר
לשעה ולהעלות שוב.
